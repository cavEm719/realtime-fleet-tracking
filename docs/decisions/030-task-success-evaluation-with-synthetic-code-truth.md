# ADR 030: Task-success evaluation with synthetic code truth

Status: accepted in the implemented experiment. History: `9f06503 / 4fe5f85`.

## Context

Tool selection alone does not prove a useful fleet answer.

## Decision

Fixed clock/data, code-derived facts, data/strict leak checks and database draft side effects, repeated realistic tasks.

## Consequences

Small synthetic coverage cannot establish production reliability or security.

Implementation, tests and limits: [design](../design/evaluation.md).
